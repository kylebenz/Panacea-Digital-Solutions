# 1. How to Use This Guide

This document combines the website brand guide with a practical SEO
content plan. It focuses exclusively on AI-assisted healthcare
advertisement videos and infographic images. It does not position web
design as a service sold by Panacea. SEO recommendations are strategic
starting points; keyword demand and competitiveness should be validated
with current keyword tools and Search Console data once the website is
live.

- Use the copy blocks as a first draft for the website, then personalize
  them to the actual service process and capabilities.

- Use one primary search intent per page and avoid repeating the same
  keywords unnaturally.

- Publish original sample work and helpful information that answers real
  buyer questions.

- Measure qualified inquiries and conversions, not rankings alone.

## SEO messaging principles

- Be specific: say “AI-assisted healthcare advertisement videos and
  infographics,” not only “digital solutions.”

- Be audience-led: explain how the service helps healthcare businesses
  communicate their services and build awareness.

- Be transparent: list deliverables, revision limits, process, and
  pricing clearly.

- Be realistic: never promise viral reach, guaranteed leads, patients,
  sales, or search rankings.

- Be original: add real process details, examples, and insights rather
  than generic AI-written filler.

## Keyword usage rules

- Use the main phrase naturally in the page title, H1, opening copy, and
  relevant subheading where it reads well.

- Use related terms only when they accurately describe the service.

- Do not create multiple near-identical pages targeting the same phrase;
  combine overlapping content where appropriate.

- Do not use “medical advice,” “treatment,” or clinical keywords as if
  Panacea provides healthcare services.

- Avoid keyword stuffing, hidden text, doorway pages, and unsupported
  location pages.

# 15. Technical SEO Implementation Checklist

- [ ] Set up Google Search Console and submit the XML sitemap.

- [ ] Set up web analytics with appropriate privacy disclosures and
  consent where required.

- [ ] Ensure the website uses HTTPS and has one preferred canonical URL
  per page.

- [ ] Use descriptive, unique page titles and meta descriptions.

- [ ] Use one clear primary H1 per page and a logical heading hierarchy.

- [ ] Create a useful XML sitemap and ensure important pages are
  indexable.

- [ ] Check robots.txt and noindex settings before launch.

- [ ] Compress images and use modern formats where supported; avoid
  oversized autoplay videos.

- [ ] Use descriptive file names and useful alt text for meaningful
  images.

- [ ] Add captions or transcripts for important video content where
  appropriate.

- [ ] Make the site responsive and test forms on mobile and desktop.

- [ ] Fix broken links, redirect retired URLs appropriately, and avoid
  duplicate pages.

- [ ] Use structured data only when accurate and eligible; validate it
  before deployment.

- [ ] Review Core Web Vitals and page performance after launch.

- [ ] Keep contact details, pricing, claims, and policies consistent
  across pages.

Do not add fake reviews, misleading structured data, keyword-stuffed
footer text, hidden content, or location pages for places where the
business has no genuine presence.
