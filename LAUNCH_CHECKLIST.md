# Launch checklist

Every item from the brand guide's **§15 Technical SEO Implementation Checklist** and
**§19 Final SEO and Brand QA Checklist**, mapped to where it stands in this build.

**Status key**

- **Done:** built and covered by a test or by the `npm run prelaunch` gate.
- **Owner:** needs a decision, fact, or account from Panacea before launch.
- **At launch:** can only be done on the production domain.
- **After launch:** ongoing.

Open facts are listed in `docs/verify-items.md`. `npm run prelaunch` fails while any
`[VERIFY]` mark is still on the page.

## Run before going live

```sh
SITE_ENV=production NEXT_PUBLIC_SITE_URL=https://<domain> npm run prelaunch   # must pass with zero failures
npm run build && ./scripts/serve.sh && BASE_URL=http://localhost:3100 npx playwright test
```
